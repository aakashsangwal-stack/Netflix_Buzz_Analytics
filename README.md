# 🎬 Netflix Buzz Analytics Dashboard

An interactive Power BI dashboard that explores Netflix's content library through data visualization, sentiment analysis, and business intelligence.

## 📌 Overview

This project analyzes Netflix titles to uncover insights into content distribution, genre performance, audience sentiment, and release trends. The dashboard was designed with a Netflix-inspired interface to deliver an engaging and interactive user experience.

## 🎯 Objectives

- Analyze the distribution of Movies and TV Shows
- Explore content across different countries and genres
- Measure audience sentiment using Buzz Score analysis
- Identify trends in Netflix content over time
- Present insights through an interactive Power BI dashboard

## 📊 Dashboard Features

- 📈 Interactive KPI Cards
- 🎬 Movies vs TV Shows Analysis
- 🌍 Top Countries by Total Titles
- 🎭 Average Buzz Score by Genre
- 😊 Sentiment Distribution
- 📅 Release Year Trend Analysis
- 🎛️ Interactive Slicers
- 💡 Custom Report Tooltips
- 🎨 Netflix-inspired UI designed in Figma
- 🖥️ Custom HTML Content Visuals

## 🔍 Key Insights

- Movies represent nearly **70%** of Netflix's content library.
- TV Shows account for approximately **30%** of the available content.
- The **United States** contributes the highest number of titles, followed by **India**.
- Netflix experienced significant growth in content releases over recent years.
- Certain genres achieved higher average Buzz Scores, indicating stronger audience engagement.
- Neutral sentiment dominates the dataset, followed by Positive and Negative sentiment.
